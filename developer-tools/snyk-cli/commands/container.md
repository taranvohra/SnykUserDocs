# Container

## Description

The `snyk container` commands test and continuously monitor container images for vulnerabilities and generate an SBOM for a container image.

For more information, see [Snyk CLI for Snyk Container](https://docs.snyk.io/snyk-cli/scan-and-maintain-projects-using-the-cli/snyk-cli-for-snyk-container)

## `snyk container` commands and the help docs

The `snyk container` commands are listed here with the help options:

* [`container test`](/broken/pages/9d1LFrp7EihaKw5fePUm), `container test --help`: tests for any known vulnerabilities
* [`container monitor`](/broken/pages/JV2hZVuofBFzc1H5K93W), `container monitor --help`: captures the container image layers and dependencies and monitors for vulnerabilities on [snyk.io](https://snyk.io)
* [`container sbom`](/broken/pages/RkhjsbT96SfM5vLk4hzx), `container sbom --help`: generates an SBOM for a container image
