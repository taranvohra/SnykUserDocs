# Use IaC custom rules with CLI

{% hint style="info" %}
Ensure you have followed the steps in [Getting Started with the SDK](/broken/pages/it8qN2FelMqEkODZnolJ) to learn how to generate a bundle of your rules.
{% endhint %}

With Snyk IaC, you can test your configuration files with the CLI using your custom rules.

There are two ways to use your built bundle:

* [Using a local custom rules bundle](/broken/pages/12qkaNc1wQ5vU2c7Vkrv) stored on your disk.
* [Using a remote custom rules bundle](/broken/pages/pRctMg1gK3DjSML8LqZK) by configuring a remote OCI Registry, where your custom rules bundle is already stored.
